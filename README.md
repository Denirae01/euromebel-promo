# EuroMebel · «Испытай удачу»: промо-лендинг

Посетитель открывает три карты, выигрывает скидку **−20% на всю мягкую мебель** и оставляет email. За этим email закрепляется уникальный промокод из загруженного пула, а заявка встаёт в очередь на отправку. Само письмо отправляет **ваш сервис рассылки** через вебхук, настройка ниже.

```
GitHub Pages (index.html)  ──POST email──►  Google Apps Script  ──►  Google Таблица
                                              │                      ├ Промокоды (пул)
                                              │                      ├ Заявки (email + код + статус отправки)
                                              │                      └ Загрузка (сюда вставляются коды)
                                              └──POST {email, code}──►  ваш сервис рассылки (WEBHOOK_URL)
check.html (салоны) ──проверить / погасить код──►  тот же Apps Script
```

Сервер и платные сервисы не нужны. Хостинг: GitHub Pages, база: Google Таблица.

---

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `styles.css`, `app.js` | лендинг |
| `config.js` | **все настройки акции**: URL API, скидка, срок, ссылки |
| `check.html` | страница для салонов: проверить и погасить промокод (PIN) |
| `backend/Code.gs` | серверная часть (Google Apps Script) |
| `assets/logo.svg` | логотип EuroMebel (вектор, снят с рекламных макетов бренда) |
| `assets/fonts/` | шрифт Jost (открытый аналог Futura PT из макетов), подключён локально |

Фирменные цвета заданы в начале `styles.css` (`:root`): красный `#E30016`, синий `#00509E`, персиковый `#FFDEA9`, голубой `#B9E5FF`. Всё взято из логотипа и рекламных макетов. Если есть лицензионные файлы Futura PT, положите их в `assets/fonts/` и раскомментируйте блок `@font-face` в `styles.css`.

## Запуск: 3 шага (~15 минут)

### 1. Сайт на GitHub Pages
Репозиторий → **Settings → Pages** → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
Свой домен (например `promo.euromebel.kz`): там же поле *Custom domain* плюс CNAME-запись в DNS.

Пока `apiUrl` в `config.js` пустой, сайт работает в **демо-режиме**: игра работает, но email никуда не сохраняется.

### 2. Бэкенд: Google Таблица + Apps Script
1. Создайте Google Таблицу (лучше под корпоративным аккаунтом), например «EuroMebel Промо SOFT20».
2. **Расширения → Apps Script** → удалите содержимое `Code.gs` → вставьте `backend/Code.gs` из репозитория → Сохранить.
3. Обновите таблицу: появится меню **Промо**. Выберите **Промо → 1. Подготовить таблицу** и разрешите доступ.
4. В Apps Script: **Развернуть → Новое развёртывание** → тип *Веб-приложение*:
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
   → Развернуть → скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
5. Вставьте этот URL в `config.js` → `apiUrl` и закоммитьте.

> После любых правок в `Code.gs`: **Развернуть → Управление развёртываниями → ✎ → Версия: новая**. Иначе будет работать старый код. URL при этом не меняется.

### 3. Промокоды
Вариант А: **свои коды из 1С / сайта.** Вставьте их в лист **«Загрузка»**, колонка A, со 2-й строки, по одному в ячейке. Затем **Промо → 2. Загрузить коды**. Дубликаты отбрасываются, коды попадают в лист «Промокоды» со статусом `свободен`.

Вариант Б: **сгенерировать.** **Промо → Сгенерировать коды…** создаст коды вида `SOFT20-7KQ2MX`. Затем выгрузите лист «Промокоды» (Файл → Скачать → CSV) и заведите коды в 1С / на сайте, чтобы касса их принимала.

Если свободные коды закончатся, посетитель увидит «Промокоды закончились». Следите за меню **Промо → Статистика**.

## Отправка писем (для IT)

Отправка отделена от сбора заявок. Заявки копятся со статусом `ожидает`, и их можно отправить в любой момент позже.

**Свойства скрипта** (Apps Script → ⚙ Настройки проекта → Свойства скрипта):

| Свойство | Значение |
|---|---|
| `WEBHOOK_URL` | URL вашего сервиса, который отправит письмо |
| `WEBHOOK_SECRET` | любая строка, приходит в заголовке `X-Promo-Secret`. Проверяйте её на своей стороне |
| `SEND_ON_CLAIM` | `true` (по умолчанию): отправлять сразу при заявке; `false`: только вручную или по таймеру |
| `STAFF_PIN` | PIN для страницы `check.html` (без него проверка кодов выключена) |
| `DISCOUNT` / `SCOPE` / `VALID_UNTIL` / `CATALOG_URL` | подставляются в письмо и вебхук |
| `SEND_VIA_GMAIL` | `true`: запасной вариант, письмо уходит из Gmail владельца таблицы. Лимит Google: 100 получателей в день для обычного аккаунта, 1 500 для Google Workspace |

**Что приходит на `WEBHOOK_URL`** (POST, JSON):
```json
{
  "email": "name@mail.kz",
  "code": "SOFT20-7KQ2MX",
  "campaign": "SOFT20",
  "discount": "−20%",
  "scope": "на всю мягкую мебель",
  "validUntil": "31.10.2026",
  "catalogUrl": "https://euromebel.kz/",
  "subject": "Ваш промокод −20% на всю мягкую мебель",
  "html": "<div>…готовое письмо…</div>"
}
```
Ответ `2xx` означает, что заявка помечается `отправлено`. Любой другой ответ даёт статус `ошибка` с текстом в колонке «Ошибка». Такие заявки уйдут при следующей отправке. Поле `html` можно не использовать, если у вашего сервиса свой шаблон.

**Отправить накопленное:** **Промо → Отправить всем, кому ещё не отправлено** или **Промо → Включить автоотправку (каждые 10 мин)**.

**Ящик-отправитель.** Письма должны уходить с адреса на домене euromebel.kz (например `promo@euromebel.kz`), и для этого домена в DNS нужно настроить SPF, DKIM и DMARC для сервиса рассылки. Без этого письма уйдут в спам.

## Салоны: проверка кода
`https://<сайт>/check.html` → название салона, PIN (`STAFF_PIN`), промокод:
- **Проверить**: действителен / уже использован (когда и где) / такого нет.
- **Погасить**: код помечается `погашен`, повторно не пройдёт.

## Защита
- один email = один код (при повторе новый код не выдаётся);
- поле-ловушка для ботов и ограничение 5 попыток в минуту на email;
- неверный PIN 20 раз → проверка блокируется на 10 минут;
- параллельные заявки защищены блокировкой (два человека не получат один код).
